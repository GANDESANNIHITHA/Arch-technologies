# Generative AI Internship – Arch Technologies

## About the Project
This repository contains the projects completed during my 2-month Generative AI Internship at Arch Technologies. The internship focused on building practical AI applications using Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and speech recognition.

## Month 1 – Offline Medical AI Chatbot
Developed an offline medical chatbot using a fine-tuned Llama 3.2 1B Instruct model.

**Key Features:**
- Fine-tuned the model using LoRA/QLoRA.
- Used the MedQuAD medical Q&A dataset.
- Applied 4-bit quantization using Unsloth.
- Integrated Ollama for local model execution.
- Developed an interactive interface using Streamlit.
- Supported offline chatbot interaction and conversation history.

## Month 2 – Advanced Generative AI Applications

### Task 3: Medical Question Answering Using RAG
- Built a medical RAG pipeline using the MedInstruct-52k dataset.
- Performed document chunking and embedding generation.
- Used Sentence Transformers for semantic embeddings.
- Implemented FAISS for vector similarity search.
- Retrieved relevant medical information for user queries.

### Task 4: AI Voice Assistant Using Whisper
- Integrated OpenAI Whisper for speech recognition.
- Used AI-generated sample audio for testing.
- Converted speech into text using transcription.
- Explored AI-powered voice processing workflows.
