# 💬 Nexa Local AI Chatbot

A simple Streamlit chatbot powered by Ollama.

The chatbot runs an AI model locally on your computer, so an OpenAI API key is not required.

## 🚀 Features

- 💬 Interactive chatbot
- 🧠 Local AI model using Ollama
- 🔒 No OpenAI API key required
- ⚡ Streamlit interface
- 📝 Maintains conversation history
- 💻 Runs locally on Windows

## 🛠️ Technologies

- Python
- Streamlit
- Ollama
- Local LLM
